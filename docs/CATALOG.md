# Curated catalog / 精选目录

Reviewed **2026-11-11**, catalog schema **2**. **116 entries**, with **49 installable/configurable integrations** and **67 reference-only tools**. The installable set contains 24 skills, 6 rule packs, 17 MCP servers, and 2 MCP-to-LSP bridges. The 18 LSP entries comprise the two installable bridges (Serena, lsp-mcp-server), the three reference-only bridges (agent-lsp, mcpls, lspyx), and 13 standalone language-server references.

Stars are dated repository-level snapshots, not scores for individual skills or rules. Multiple entries from ECC, Superpowers, agent-skills, or another monorepo share the same repository evidence. The executable source of truth is [`catalog.json`](../src/awesome_python_dev/data/catalog.json); every entry records its source, license, review date, and installation status.

## Browse and select

```sh
apd profiles
apd list --installable
apd list --kind rules
apd list --kind lsp
apd list --category framework-best-practices --installable
apd init --agents codex --profile django --dry-run
```

`install: null` means the CLI lists the tool and its upstream setup guidance. An installable skill copies the pinned skill directory. A rule pack selects and activates reviewed Markdown rules for the chosen agent. A configurable MCP entry writes a pinned server launch configuration; the coding agent starts it later. Serena uses that MCP path to expose language-server capabilities.

## Selection, verification, and maintenance

Admission considers the coding task served, documented setup, maintenance activity, license, upstream identity, and whether a reproducible integration can be tested. The catalog separates source/configuration checks from runtime operation. Inclusion does not claim every upstream feature or every agent version was tested.

See [research and verification evidence](RESEARCH.md), [ECC migration details](ECC-MIGRATION.md), [LSP and security-tool setup](LSP.md), and [agent configuration paths](AGENTS.md).

**Updates are curated and pinned.** Refreshing installed instructions regenerates them from the catalog shipped with this CLI version. It does not watch upstream repositories, follow their default branches, or silently adopt new skills/rules. A catalog update requires reviewing upstream changes and licenses, selecting a new pin, recomputing archive hashes where applicable, updating these documents, and testing the installation lifecycle.
- **ast-grep:** [Structural search, linting and rewriting by AST pattern](https://github.com/ast-grep/ast-grep) rather than by text, which is the difference that matters when an agent is asked to change every occurrence of one code shape across a project. It stays reference-only because the delivered unit is a native CLI built from a Rust workspace (`crates/`: `cli`, `core`, `language`, `config`, `dynamic`, `lsp`, `outline`, `napi`, `pyo3`, `wasm`) and not one of this catalog's install types: the Python route is the published package `ast-grep-cli` (root `pyproject.toml`, built with maturin from `crates/pyo3`), which belongs in a project environment next to `ruff` and `deptry` rather than in a client configuration, and the CLI's own `lsp` subcommand (`crates/cli/src/lsp.rs`) serves ast-grep rule diagnostics to an editor rather than the Python language intelligence the LSP entries here provide. Python patterns are parsed by `crates/language/src/python.rs`. Nothing was installed and no search or rewrite was run.
- **claude-plugins-official:** [The directory Anthropic maintains for Claude Code plugins](https://github.com/anthropics/claude-plugins-official): `.claude-plugin/marketplace.json` lists 317 plugins — skills, agents, hooks, commands and MCP servers — installed with `/plugin install <name>@claude-plugins-official`, with 14 partner entries under `external_plugins/` and the first-party ones grouped under `plugins/`. Use it to choose a plugin, including the MCP servers already recorded here (`serena`, `context7`, `playwright`, `github`), and note the README's own boundary: Anthropic does not control the MCP servers, files or software inside third-party plugins and cannot verify they behave as intended.
